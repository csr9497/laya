Especificación del Formato Laya

Estructura estricta para cada uno de los 3 tipos soportados.

1. Tipo `choice` (Jerarquía de Opciones y Criterios):

Requiere un diccionario en criteria donde las claves son las opciones que puede retornar el modelo y los valores son descripciones semánticas que justifican cada opción.

"departamento": {
  "type": "choice",
  "instructions": "¿Qué departamento debe atender esto?",
  "criteria": {
    "facturacion": "invoices, facturas, cobros y reembolsos",
    "soporte": "errores técnicos, caídas de servicio, bugs",
    "ventas": "cotizaciones y planes comerciales"
  }
}
2. Tipo `score` (Escalas Ordenadas por Niveles):

Requiere una lista en criteria ordenada de menor a mayor intensidad (Nivel 0, Nivel 1, Nivel 2...). Retorna el valor esperado numérico.

"urgencia": {
  "type": "score",
  "instructions": "¿Qué nivel de urgencia tiene?",
  "criteria": [
    "baja: sin prisa ni plazos estrictos",
    "media: requiere atención pronto",
    "bloqueante: interrupción total o pérdida financiera"
  ]
}
3. Tipo `noul` (Booleano Sí / No / Probabilidad):

Evalúa una afirmación binaria y retorna la probabilidad P(true) de 0.0 a 1.0.

"amenaza_baja": {
  "type": "noul",
  "instructions": "¿El cliente amenaza con cancelar su servicio?"
}
